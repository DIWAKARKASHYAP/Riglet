Three jobs. One browser.

        

          

            01
            
API parameter lab

            

              Intercept query, headers, cookies, GraphQL variables, and
              WebSocket frames. Import OpenAPI, Postman, or HAR. Mock status,
              latency, and broken bodies so the frontend can fail on purpose.
            

          

          

            02
            
Agentic scraper

            

              Goal in, typed JSON out. Schema, pagination, login-aware
              sessions. The agent reads the live page — not a dumb fetch — and
              writes CSV or JSON you can assert against.
            

          

          

            03
            
Keyboard and mouse

            

              Real input: click, type, hover, drag, file dialogs, IME. Plus an
              accessibility snapshot with stable refs so the agent is not
              screenshot-only. Windows file pickers included — headless dies
              here.
